## 📌 Featured Engineering Projects

### ⚡ [Integrated Power-to-Methane (PtM) ML Optimization](https://github.com/mustafaChemEng/PtM-Thermal-ML-Optimization)
*   **Tech Stack:** AVEVA Process Simulation, Python, XGBoost, Pinch Analysis
*   **Scope:** Engineered a 10,000 Nm³/h PtM facility. Synthesized a 14-exchanger network to achieve total thermal autarky (0 MW external hot utility). Deployed an XGBoost surrogate model to optimize operating pressures and interstage cooling, saving ~400 kW of continuous compressor load while maintaining 98.47% methane purity.

### ♻️ [4-Bed Pressure Swing Adsorption (PSA) Digital Twin](https://github.com/mustafaChemEng)
*   **Tech Stack:** AVEVA APS LaaS, MATLAB, Python
*   **Scope:** Developed a comprehensive dynamic simulation and optimization framework for a 4-bed PSA system focused on biogas purification and component separation.

### 🌱 [Sustainable Green Urea Production](https://github.com/mustafaChemEng)
*   **Tech Stack:** Chemical Process Design
*   **Scope:** Graduation design project focused on the sustainable production of green urea from captured CO2 and imported green ammonia utilizing the Bosch-Meiser process.

### 💧 [SafaWater Solution (Clean-Tech Venture)](https://github.com/mustafaChemEng)
*   **Scope:** Developed the technical framework for a renewable-powered, off-grid water purification system utilizing hybrid ultrafiltration and reverse osmosis powered by solar energy and fuel cells.
